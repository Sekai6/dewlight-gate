# v1.5.0 — 连招、打击感与更聪明的敌人

- **连招**：J 改为三段连斩，第三段是前踏重斩；空中为独立的空中斩。按键有 0.2 秒输入缓冲，出招中、冲刺中按下都会在可用时放出。招式命中后可立刻接下一招、冲刺或跳跃；打空要等收招。
- **打击感**：顿帧、震屏、击退、命中音效都按招式配置，只在真正命中时触发。技能命中回复少量光能；命中点有斩痕与冲击环。「露华回旋」会把小怪吸近再弹开，守卫被命中时身体后仰。三个技能的特效分层重画。
- **布娃娃**：主控被击飞时躯干会弯、落地躺平再起身，关节不穿地，弹地和撞墙有反应，空中受身会蜷身翻正。小怪被击败时被打飞、翻滚、躺平后淡出。
- **敌人**：小怪会察觉、追击、保持距离、看时机出手；苔影会后跳，玻璃蛾会从头顶掠到另一侧。多只同场时轮流进攻，同时最多两只，生命不多时只有一只。守卫按距离、你是否在空中或靠墙、以及你应对预警的习惯选招，不再固定循环；预警时长、命中范围、伤害和生命值不变。
- **引擎开源**：动画引擎与技能运行时拆成两个不含游戏内容的包（`packages/action-a`、`packages/action-skill`），并在 [Kisara-Lab/action-a](https://github.com/Kisara-Lab/action-a) 单独开源。尚未发布到 npm。

存档格式不变，旧存档可直接继续。

## 手感变化

- 普攻命中后约 0.15 秒可接下一段；任何招式都可以从收招段接任何招式。
- 技能释放中按跳跃不响应，除非已经命中；普攻中跳跃照常。普攻全程锁定朝向。
- 被重击后的翻滚与起身比 v1.4.0 多约 0.1 秒；空中受身 0.12 → 0.20 秒。
- 站着不动更危险（小怪会追上来）；正常走位或进攻时受击次数与 v1.4.0 持平或更少。

## 验证

30 项单元测试、5 项浏览器冒烟测试（本地运行）、格式检查、TypeScript 与生产构建通过。拆包前后约 2.5 万帧逐帧对照一致。连招时序、小怪与守卫行为用固定输入在实际游戏中回放核对过。

## 限制

- 线上 CI 只跑格式、单元测试和构建，浏览器测试在本地运行。本版没有附带对照录像包。
- 玻璃蛾只保持水平距离，没有绕飞轨迹；地面小怪不会主动绕到另一侧。挑战难度下守卫的读招只有单元测试覆盖。
- 仍仅支持桌面键盘；WebGPU 不可用时回退 Canvas；Phaser 主包仍较大。
